# TrainingLog 1.1.0

Второй публичный релиз.

## Что нового

- горячие клавиши: каждой команде каждого окна можно назначить свою комбинацию
  во вкладке «Горячие клавиши» окна параметров; комбинация набирается захватом —
  Esc возвращает прежнее значение, буква без модификатора не подтверждается,
  конфликт внутри окна показывает красную строку и гасит «Сохранить»;
  назначение действует сразу после сохранения, до него работают умолчания:
  `Ctrl+S` — «Сохранить» в окне дня, стрелки — выделение строк журнала;
- строки журнала выбираются стрелками клавиатуры, выбор сохраняется после мыши,
  контекстного меню и возврата из окна дня;
- окно правки дня: Tab идёт по цепочке «все веса, затем все повторения»,
  при смене активного упражнения фокус переносится в повторения первого подхода;
- параметры: выбор директории и файла базы (`*.db`), место хранится в
  `settings.json`; после смены адреса приложение предлагает перезапуститься
  сразу, при неудачном запуске предупреждает и продолжает работу;
- шрифт приложения меняется в параметрах: поиск среди системных семейств,
  размер — пресетами; настройка сразу применяется ко всем окнам и хранится в
  `settings.json`;
- оформление: собственная светлая тема вместо системных цветов, единый
  стеклянный стиль всех кнопок, собственная полоса заголовка с кнопками
  свернуть-развернуть-закрыть; активное окно выделяется линией под заголовком;
- журнал и окно дня работают быстрее за счёт оптимизации чтения базы.

`settings.json` предыдущей версии остаётся пригодным: новые поля (адрес базы,
шрифт, горячие клавиши) дописываются при первом сохранении, до этого работает
умолчание.

## Что скачать

- `TrainingLog-1.1.0-win-x64.exe` — один файл, нужен .NET 10 Desktop Runtime;
- `TrainingLog-1.1.0-win-x64-selfcontained.zip` — папка со своим рантаймом, ничего
  доустанавливать не надо.

## Требования

- Windows 10/11 x64;
- .NET 10 Desktop Runtime только для варианта одним файлом.

База SQLite создаётся сама, миграции применяются при старте, файл по умолчанию
лежит в `%LOCALAPPDATA%\TrainingLog\exercises.db` — место можно перенести в
параметрах.

## Замечание

exe не подписан, поэтому Windows может показать предупреждение SmartScreen:
«Подробнее» → «Выполнить».
