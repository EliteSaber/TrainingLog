# TrainingLog 1.0.0

Первый публичный релиз.

## Что умеет

- ведёт журнал тренировок, показываются последние дни (от 1 до 366, меняется в
  параметрах), на дату одна запись — база следит за этим сама; день добавляется
  и правится из окна, двойным кликом или через меню строки;
- при добавлении дня подтягивает прошлый день с тем же планом: веса — значениями,
  повторения — плейсхолдером, который в запись не попадает, пока не набран заново;
- окно дня: план, упражнения плана по порядку, подходы с весом и повторениями,
  примечания дня и каждого упражнения; вес нового подхода наследует предыдущий;
- справочник упражнений: добавление, переименование, удаление, сортировка и фильтр;
  имя задаётся непустым и не длиннее 100 символов, повторы (и по регистру) блокирует
  база;
- импорт справочника из файла (UTF-8 и windows-1251, при желании с очисткой) и экспорт
  справочника в файл;
- планы тренировок: состав с порядком выполнения, перестановка кнопками, «На основе» —
  разовый перенос состава из другого плана, после которого планы независимы;
- файл параметров `settings.json` рядом с программой, при первом запуске создаётся
  сам.
- числовые поля принимают только цифры и разделитель, отказ объясняет всплывающая
  подсказка; так же показываются примечания и отказы сохранения.

## Что скачать

- `TrainingLog-1.0.0-win-x64.exe` — один файл, нужен .NET 10 Desktop Runtime;
- `TrainingLog-1.0.0-win-x64-selfcontained.zip` — папка со своим рантаймом, ничего
  доустанавливать не надо.

## Требования

- Windows 10/11 x64;
- .NET 10 Desktop Runtime только для варианта одним файлом.

База SQLite создаётся сама, миграции применяются при старте, файл лежит в
`%LOCALAPPDATA%\TrainingLog\exercises.db`.

## Замечание

exe не подписан, поэтому Windows может показать предупреждение SmartScreen:
«Подробнее» → «Выполнить».
