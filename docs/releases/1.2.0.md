# TrainingLog 1.2.0

Третий публичный релиз.

## Что нового

- список дней строится частично — только видимые строки, контейнеры при прокрутке переиспользуются;
- скролл внутри списка больше не съедает нажатие, строка выделяется как прежде, повторный клик
  снимает выделение;
- перечитывание журнала не уводит читателя на другой день: новый день сверху больше
  не сдвигает список — журнал остаётся на той же строке; у начала журнала новый день
  появляется перед глазами;
- перестроение видимых списков (справочник упражнений, планы) ищет место элемента
  сразу, а не перебором;
- горячие клавиши из файла настроек разбираются одинаково: имена клавиш приводятся к
  одному виду, негодная запись не роняет приложение при запуске;
- переименование упражнения в справочнике сразу отражается в списках.

## Что скачать

- `TrainingLog-1.2.0-win-x64.exe` — один файл, нужен .NET 10 Desktop Runtime;
- `TrainingLog-1.2.0-win-x64-selfcontained.zip` — папка со своим рантаймом, ничего
  доустанавливать не надо.

## Требования

- Windows 10/11 x64;
- .NET 10 Desktop Runtime только для варианта одним файлом.

База SQLite создаётся сама, миграции применяются при старте, файл по умолчанию
лежит в `%LOCALAPPDATA%\TrainingLog\exercises.db` — место можно перенести в
параметрах.

## Замечание

exe не подписан, поэтому Windows может показать предупреждение SmartScreen:
«Подробнее» → «Выполнить».
