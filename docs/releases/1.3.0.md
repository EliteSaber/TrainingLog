# TrainingLog 1.3.0

Четвёртый публичный релиз.

## Что нового

- тёмная тема: в параметрах выбирается светлая, тёмная или системная; системная
  следует за темой Windows и переключается на лету;
- окно параметров переработано: вкладки «Общие», «Горячие клавиши» и «Окна»;
  в клавишах — поиск по действию и окну, фильтр «только изменённые» и переходы
  по окнам; в «Окнах» — размер каждого окна, число вводится в поле или меняется
  перетаскиванием, правка сразу показывается на открытых окнах, «Отмена»
  возвращает прежние размеры;
- окна можно закреплять поверх остальных кнопкой на полосе заголовка;
- окна правки и импорта упражнений, плана и параметров стали отдельными вместо
  модальных: между ними можно переключаться, сворачивание журнала их не прячет;
- в окне плана строки выбираются мышью и стрелками, перемещённая строка остаётся
  в поле зрения, выделение при перестановке упражнений не сбрасывается;
- исправления оформления: меню и его разделитель, длинный заголовок обрезается
  с подсказкой при наведении, день недели в дате источника окна дня, кнопка
  «Добавить день» подстраивается под размер шрифта, у окна правки упражнения
  нельзя растянуть высоту вручную.

`settings.json` предыдущей версии остаётся пригодным: новые поля (`Theme`,
`WindowSizes`) дописываются при сохранении, до этого работают умолчания.

## Что скачать

- `TrainingLog-1.3.0-win-x64.exe` — один файл, нужен .NET 10 Desktop Runtime;
- `TrainingLog-1.3.0-win-x64-selfcontained.zip` — папка со своим рантаймом, ничего
  доустанавливать не надо.

## Требования

- Windows 10/11 x64;
- .NET 10 Desktop Runtime только для варианта одним файлом.

База SQLite создаётся сама, миграции применяются при старте, файл по умолчанию
лежит в `%LOCALAPPDATA%\TrainingLog\exercises.db` — место можно перенести в
параметрах.

## Замечание

exe не подписан, поэтому Windows может показать предупреждение SmartScreen:
«Подробнее» → «Выполнить».
